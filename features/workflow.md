# Workflow

A2A Identity Toll is a paid remote MCP gate for caller identity, target agent scope, task intent, data class, policy verdicts, and audit receipts.

## Repeatable Flow

1. Submit caller identity, target agent, scope, and task intent.
2. Evaluate the request against team policy and data class.
3. Return allow, review, or deny with structured reasons.
4. Archive a receipt for audit and incident follow-up.

## Output Mindset

The useful artifact is not a marketing claim. It is evidence that a reviewer can inspect, export, and compare later.
